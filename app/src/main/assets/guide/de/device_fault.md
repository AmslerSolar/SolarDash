# Störung

Das Gerät meldet eine Störung. Der Text unter der Meldung ist die Beschreibung und der Code, die das Gerät selbst liefert.

## Was tun

1. **Schreib den angezeigten Code auf** (zum Beispiel «F04» oder «Fault code 0x0123») und die Uhrzeit.
2. Viele Störungen verschwinden von selbst, zum Beispiel nach einer kurzen Netzstörung. Warte **15 Minuten**.
3. Bei einer Inselanlage mit einer Überlast-Störung: Schalte grosse Geräte aus (Wasserkocher, Heizung, Waschmaschine) und warte dann.
4. Wenn die Störung bleibt oder wiederkommt: **Ruf deinen Installateur an** und nenne ihm den Code.

! Öffne nie den Wechselrichter, die Batterie oder die Anschlusskästen. Sie führen gefährliche Spannungen, auch wenn sie ausgeschaltet sind. Schalte die Anlage nur aus und wieder ein, wenn das Handbuch oder dein Installateur dir erklärt, wie das geht.
