# Backup mode

The inverter supplies the house from the battery (and the solar panels), without the grid. On a system with a grid connection this usually means there's a **power cut**; on an off-grid system it's the normal state.

## What to do

1. **Use as little power as possible** while the grid is down, so the battery lasts longer: switch off heaters, kettles, washing machines and pumps.
2. Check whether the neighbours have power. If they do, check the main switch, the residual-current device (RCD) and the fuses in the distribution board.
3. When the grid is back, the inverter switches back by itself, usually within a few minutes.

If the system stays in backup mode although the grid is back, call your installer.

! Don't work on the distribution board yourself unless you know how to do it safely.
