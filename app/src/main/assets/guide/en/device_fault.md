# Fault

The device reports a fault. The text below the message is the device's own description and code.

## What to do

1. **Write down the code** shown (for example "F04" or "Fault code 0x0123") and the time.
2. Many faults clear by themselves, for example after a short grid disturbance. Wait **15 minutes**.
3. On an off-grid system with an overload fault: switch off large appliances (kettle, heater, washing machine), then wait.
4. If the fault stays or comes back: **call your installer** and tell them the code.

! Never open the inverter, the battery or the connection boxes. They carry dangerous voltages, also when they are switched off. Only switch the system off and on if the manual or your installer tells you how.
