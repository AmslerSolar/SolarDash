# Login failed

The device asks for a password or access token, and doesn't accept the one stored in the app.

## What to do

- **LG ESS:** the password is the inverter's network (MAC) address, in lowercase without colons. Check it on the inverter's label and edit the device in the app.
- **Enphase:** the access token is only valid for a limited time. Create a new token in the Enphase account and enter it when editing the device.
- Other devices: enter the password the installer set, by editing the device in the app.

If you don't know the password, call your installer.
