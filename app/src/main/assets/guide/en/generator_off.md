# No AC input

No generator or grid power reaches the inverter. The system runs on the battery and the solar panels. On an off-grid system this is normal whenever the generator is off.

## What to do

- Nothing, as long as the battery has enough charge.
- If the battery is getting low: start the generator (if there is one) as you usually do.
- If the generator runs but this message stays: check the generator's output switch and the cable to the inverter, and that the generator has fuel.
