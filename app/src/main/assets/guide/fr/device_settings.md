# Vérifier les réglages

L’appareil répond, mais pas avec les données attendues par l’application. En général, l’appareil fonctionne normalement ; seuls les réglages de connexion ne correspondent pas.

## Raisons fréquentes

- Le **type d’appareil** choisi dans l’application ne correspond pas à l’appareil (par exemple après le remplacement d’un onduleur).
- L’**ID d’unité** (adresse Modbus) est incorrect.
- Une mise à jour du firmware a modifié les réglages de l’appareil.

## Que faire (installateur)

1. Ouvrez l’onglet **Appareils** de l’installation et modifiez l’appareil.
2. Utilisez **Rechercher sur le réseau** pour le retrouver, ou comparez le type, le port et l’ID d’unité avec les réglages de l’appareil.
3. Le texte sous le message montre la réponse de l’appareil lui-même, ce qui aide au diagnostic.
