# Défaut

L’appareil signale un défaut. Le texte sous le message est la description et le code fournis par l’appareil lui-même.

## Que faire

1. **Notez le code** affiché (par exemple « F04 » ou « Fault code 0x0123 ») et l’heure.
2. Beaucoup de défauts disparaissent d’eux-mêmes, par exemple après une courte perturbation du réseau. Attendez **15 minutes**.
3. Sur une installation autonome (hors réseau) avec un défaut de surcharge : éteignez les gros appareils (bouilloire, radiateur, machine à laver), puis attendez.
4. Si le défaut persiste ou revient : **appelez votre installateur** et donnez-lui le code.

! N’ouvrez jamais l’onduleur, la batterie ou les boîtiers de raccordement. Ils sont sous des tensions dangereuses, même lorsqu’ils sont éteints. N’éteignez et ne rallumez le système que si le manuel ou votre installateur vous explique comment faire.
