# Mode secours

L’onduleur alimente la maison depuis la batterie (et les panneaux solaires), sans le réseau. Sur une installation raccordée au réseau, cela signifie généralement une **coupure de courant** ; sur une installation autonome, c’est l’état normal.

## Que faire

1. **Consommez le moins possible** tant que le réseau est coupé, pour que la batterie tienne plus longtemps : éteignez chauffages, bouilloires, lave-linge et pompes.
2. Vérifiez si les voisins ont du courant. Si oui, contrôlez l’interrupteur principal, le disjoncteur différentiel (DDR) et les fusibles du tableau électrique.
3. Quand le réseau revient, l’onduleur se reconnecte de lui-même, en général en quelques minutes.

Si l’installation reste en mode secours alors que le réseau est revenu, appelez votre installateur.

! N’intervenez pas vous-même sur le tableau électrique, sauf si vous savez le faire en toute sécurité.
