# Accesso non riuscito

Il dispositivo chiede una password o un token di accesso, e non accetta quello salvato nell’app.

## Cosa fare

- **LG ESS:** la password è l’indirizzo di rete (MAC) dell’inverter, in minuscolo e senza i due punti. Leggilo sull’etichetta dell’inverter e modifica il dispositivo nell’app.
- **Enphase:** il token di accesso vale solo per un tempo limitato. Crea un nuovo token nell’account Enphase e inseriscilo quando modifichi il dispositivo.
- Altri dispositivi: inserisci la password impostata dall’installatore, modificando il dispositivo nell’app.

Se non conosci la password, chiama il tuo installatore.
