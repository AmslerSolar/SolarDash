# Fallo

El dispositivo informa de un fallo. El texto debajo del mensaje es la descripción y el código del propio dispositivo.

## Qué hacer

1. **Apunta el código** que aparece (por ejemplo «F04» o «Fault code 0x0123») y la hora.
2. Muchos fallos desaparecen solos, por ejemplo después de una breve perturbación de la red. Espera **15 minutos**.
3. En una instalación aislada (sin red) con un fallo por sobrecarga: apaga los aparatos grandes (hervidor, estufa, lavadora) y luego espera.
4. Si el fallo continúa o vuelve: **llama a tu instalador** y dile el código.

! No abras nunca el inversor, la batería ni las cajas de conexión. Tienen tensiones peligrosas, también cuando están apagados. Apaga y enciende el sistema solo si el manual o tu instalador te explican cómo hacerlo.
